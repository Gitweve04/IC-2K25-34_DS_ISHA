📖 About This Repository

This repository contains the practical implementations and programs covered in the Data Structures Laboratory as part of the MCA 3rd Semester curriculum.

The objective of this repository is to understand fundamental data structures, their operations, implementation techniques, and algorithms using C++.

It serves as a collection of laboratory assignments, practical programs, and implementations based on the prescribed Data Structures syllabus.

---

📌 Topics Covered


1. Arrays

- Array Operations
- Insertion and Deletion
- Searching and Traversal
- One-Dimensional and Two-Dimensional Arrays

2. Linked Lists

- Introduction to Linked Lists
- Singly Linked List
- Doubly Linked List
- Circular Linked List
- Insertion and Deletion Operations
- Traversal and Searching

3. Stacks

- Stack Implementation Using Arrays
- Push Operation
- Pop Operation
- Peek / Top Operation
- Stack Overflow and Underflow
- Applications of Stack

4. Queues

- Queue Implementation Using Arrays
- Enqueue and Dequeue Operations
- Circular Queue
- Priority Queue
- Queue Traversal

5. Trees

- Introduction to Trees
- Binary Trees
- Binary Search Trees (BST)
- Tree Traversals:
  - Inorder
  - Preorder
  - Postorder
- Insertion and Searching in Trees

6. Graphs

- Introduction to Graphs
- Directed and Undirected Graphs
- Weighted and Unweighted Graphs
- Graph Representation:
  - Adjacency Matrix
  - Adjacency List
- Breadth First Search (BFS)
- Depth First Search (DFS)

7. Searching Algorithms

- Linear Search
- Binary Search

8. Sorting Algorithms

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort
- Radix Sort
